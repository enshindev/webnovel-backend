# memory（S2）

长篇一致性的核心模块，负责：

- 章节保存后的抽取流水线（摘要、实体、伏笔、时间线、向量）。
- 变更建议 → 作者确认 → 写回设定库/伏笔/时间线。
- 分层摘要与向量索引的过期、重建。
- 业务检索选择：人物/地点/伏笔/相关章节片段，输出 `ContextSegment`。

与 `llm/` 的分工：

- `llm/retrieval/` 提供通用机制（向量、BM25、RRF、重排）。
- `llm/context/` 提供预算、压缩、渲染、manifest。
- `memory/` 决定“取哪些、按什么业务规则取”，是内容/业务逻辑。

S2 再落代码；目录先占位，避免以后把业务检索塞进 `llm/`。
